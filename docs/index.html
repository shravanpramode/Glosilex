Corpus freshness

The two dates mean different things.
Published version — the newest amendment the governing body has issued, fetched live from eCFR when this report was generated.
Version held — the version of the document sitting in our corpus. This is a document date, not an activity date.
Last refreshed — when our pipeline last wrote this document into Supabase. This is an activity timestamp.
A document can be refreshed today and still hold a 2024 version, if 2024 is the newest amendment that exists. That is correct, not stale.
